# Syndicate 007

**AI Business OS / Opportunity-to-Income OS — an owner-controlled product direction.**

Intelligence. Automation. Growth.

Goal → Opportunity → Action → Owner Control → Measurement → Learning → Money.

An AI answer alone does not establish execution, evidence, approval or economics.
S7 brings those boundaries into a local-first owner cockpit. The product story is
useful outcomes and controlled workflows, not a claim about hundreds of active agents.

## Current capabilities

Locally validated private implementation: opportunity ingestion, deterministic demand
analysis, execution plans with S7/human/specialist split, commercial drafts and owner
gates. MEDIA: idea → brief → production → owner review → publication package → manual
result → learning → next experiment. Shared summaries distinguish recorded/estimated
costs and unknown economics. Request != client; plan != execution; approval != sending.

Owner-first autonomy: publication, spending and external actions require separate
authorization. Eligibility unknown is not PASS. Learning proposes tests, not proven
causality or automatic social publication. No autonomous income, proven ROI, paying
customers, production scale or commercially validated acquisition is claimed.

## What this public candidate contains

Documentation, a standard-library offline replay runner, a model-validated synthetic
contract fixture and a static HTML walkthrough. NOT the production application/SDK.
The replay uses projections of real existing contract fields, validated during
preparation; it does not distribute or execute the private analysis/orchestration.
Every scenario value is SYNTHETIC, not market/client/performance evidence.

## Safe run and demo

Open `demo.html` directly in a browser. Optional: existing Python 3.10+:

```text
python demo_runner.py
```

From anywhere, pass the runner file path to Python; its adjacent fixture is fixed.
Standard library only; no server, package install, credentials, network, downloads,
database or elevated shell. It reads only the supplied fixture and writes nothing.
See DEMO.md and SCREENSHOT_KIT.md. Screenshots/recording need final owner review.
